# Font licenses

SmartMerch loads fonts from the following Fontsource packages. All bundled font
families are licensed under the SIL Open Font License 1.1 (OFL-1.1). Installing
the packages also installs each family's copyright notice and full license file
inside `node_modules/@fontsource/<package>/LICENSE`.

| Catalog ID | Font | Package | License |
| --- | --- | --- | --- |
| `wenkai` | LXGW WenKai | `@fontsource/lxgw-wenkai` | OFL-1.1 |
| `sans` | Noto Sans SC | `@fontsource/noto-sans-sc` | OFL-1.1 |
| `serif` | Noto Serif SC | `@fontsource/noto-serif-sc` | OFL-1.1 |
| `xiaowei` | ZCOOL XiaoWei | `@fontsource/zcool-xiaowei` | OFL-1.1 |
| `kuaile` | ZCOOL KuaiLe | `@fontsource/zcool-kuaile` | OFL-1.1 |

| `brush` | Ma Shan Zheng | `@fontsource/ma-shan-zheng` | OFL-1.1 |
| `hand` | Long Cang | `@fontsource/long-cang` | OFL-1.1 |

sold as standalone products. Generated poster images may be used freely under
the OFL terms.
